Hi, I'm **triger116rus/triger116rus* — a technical support engineer specializing in **enterprise storage and virtualization**.

### What I do

- **HPE storage support**: HPE 3PAR / StoreServ, Primera, Synergy 12000 composable systems, SimpliVity hyperconverged — troubleshooting, performance analysis, incident investigation.
- **VMware environments**: vSphere/ESXi administration, Horizon VDI, diagnostics and lifecycle operations.

### Typical projects

| Project type | What it involves |
|---|---|
| Storage performance analysis | Collecting and analyzing array performance metrics, identifying bottlenecks, capacity planning |
| Unstable-hardware investigations | Root-cause analysis of flapping/failing components from vendor logs and dumps |
| Upgrade planning | Versioned, verifiable upgrade plans with rollback procedures and risk assessment |
| Incident deep-dives | Parsing raw device logs (tape libraries, drives, arrays) and turning them into actionable reports |

### Home lab

I run a multi-hypervisor lab (ESXi, Proxmox, Hyper-V, oVirt) with internal services:

- an internal **projects portal** (FastAPI + SQLite, Docker) for tracking my work;
- a **knowledge base** for storage troubleshooting — PostgreSQL with full-text search and vector embeddings (pgvector), loaded with known-issues databases and vendor documentation;
- **AI-assisted workflows**: I use agentic coding tools (Claude Code and similar) with custom skills and subagent pipelines for log analysis, report writing and infrastructure planning.

| Тип проекта | Что в него входит |
